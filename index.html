ESP8266 Mikrokontrolcü Entegrasyonu

ESP8266 modülünüz Firebase yerine doğrudan yerel ağınızdaki bu JSON dosyasını okuyarak lamba durumunu takip eder:

http://localhost:8000/data.json

İpucu: Bilgisayarınızın yerel IP adresi (örn. 192.168.1.xxx:8000/data.json) ile ESP8266 kodunuzdan HTTP GET yaparak lamba anahtarını kontrol edebilirsiniz.

İşlem başarıyla gerçekleşti.
